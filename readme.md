# 🤖 AI-Powered Sales Analytics

## 📌 Project Overview

AI-Powered Sales Analytics is an end-to-end data analytics project designed to transform a deliberately dirty sales dataset into meaningful business insights using Python, MySQL, data visualization, and Generative AI.

The project combines traditional data analytics with an AI Sales Analyst that can interpret calculated business metrics and answer natural-language business questions.

---

## 🎯 Project Objective

The main objectives of this project are to:

- Clean and validate real-world style sales data
- Store and analyze sales data using MySQL
- Calculate important sales and profitability KPIs
- Analyze products, customers, regions, and salespeople
- Identify business trends and performance patterns
- Create meaningful visualizations
- Use Generative AI to interpret analytical results
- Build a portfolio-ready end-to-end analytics workflow

##AI Sales Analyst

An end-to-end sales analytics project that combines **Python, Pandas, NumPy, MySQL, Matplotlib, Seaborn, Excel, and Gemini AI** to transform a deliberately dirty sales dataset into actionable business insights.

The project covers the complete analytics lifecycle:

**Data Cleaning → SQL Analysis → Python Analytics → Visualization → Business Insights → AI Sales Analyst**

## 🎯 Business Problem

Businesses generate large amounts of sales data, but raw data often contains missing values, duplicates, inconsistent formats, invalid values, and other quality issues.

This project addresses the problem by building a complete analytical workflow that:

- Cleans and validates raw sales data
- Stores structured data in MySQL
- Calculates important sales and profitability KPIs
- Identifies high-performing products, customers, regions, and salespeople
- Analyzes sales and profit trends
- Uses Generative AI to interpret analytical results
- Provides natural-language business recommendations

## 🤖 AI Sales Analyst Architecture

The AI component does not directly perform the numerical calculations on the raw dataset.

Instead, Python first calculates and validates the business metrics. These results are then provided to Gemini for interpretation.

```text
Sales Dataset
      ↓
Pandas / NumPy
      ↓
Verified Business Metrics
      ↓
Gemini API
      ↓
AI Business Analysis
      ↓
Risks + Opportunities
      ↓
Recommendations
